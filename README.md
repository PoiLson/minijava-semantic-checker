In order to run the semantic checker for MiniJava you can check out the Makefile I have made. If you run the command:

make all

compiles the code and runs it with some tests I have included in the repository, you can change them to anything you want!

If you want to run step-by-step the commands there are these:

make compile -> compiles everything

make run -> runs the code with the files I have given into it!
